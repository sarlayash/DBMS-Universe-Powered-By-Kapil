## 🎯 The Core Learning Journey (Levels 0 → 25)

1. **Level 0 — Data Before Databases (The File System Era)**: Experience why flat files (txt, csv) collapse under concurrency, data redundancy, inconsistency, and lack of atomicity.
2. **Level 1 — Why DBMS?**: The 3-tier ANSI/SPARC schema architecture, data abstraction, and logical/physical data independence.
3. **Level 2 — Database Fundamentals**: Tables, attributes, tuples, domains, and the key hierarchy (Primary, Candidate, Super, Alternate, Foreign keys).
4. **Level 3 — Relational Model & Relational Algebra**: Interactive playground with Selection ($\sigma$), Projection ($\pi$), Join ($\bowtie$), Union ($\cup$), and Cartesian Product ($\times$).
5. **Level 4 — SQL Zero**: Hands-on DDL (`CREATE`, `ALTER`, `DROP`, `TRUNCATE`), DML (`INSERT`, `UPDATE`, `DELETE`), and DQL (`SELECT`).
6. **Level 5 — SQL Power**: Advanced filtering (`WHERE`, `ORDER BY`, `GROUP BY`, `HAVING`, `DISTINCT`, `LIMIT`), aggregates, string, and math functions.
7. **Level 6 — Mastering Joins**: Signature **Visual Join Simulator** showing row-by-row survival across `INNER`, `LEFT`, `RIGHT`, `FULL OUTER`, `CROSS`, and `SELF` joins.
8. **Level 7 — Subqueries & Nested Queries**: Correlated subqueries, `EXISTS`, and the classic interview challenge: "Find the 2nd Highest Salary".
9. **Level 8 — Database Design & ER Modeling**: Entities, cardinalities (1:1, 1:N, M:N), weak entities, and algorithms to map ER diagrams into tables.
10. **Level 9 — Normalization**: Signature **"Fix the Database" Workbench** eliminating insertion, update, and deletion anomalies through 1NF, 2NF, 3NF, and BCNF.
11. **Level 10 — Transactions & Concurrency**: ACID properties, **Bank Transfer Crash Simulator**, Dirty Read, Lost Update, Phantom Read, and Isolation Levels.
12. **Level 11 — Indexing & Physical Storage**: Interactive **B-Tree Index Explorer** comparing $O(\log N)$ binary tree search against full table scans ($O(N)$ disk I/O).
13. **Level 12 — Query Optimization**: Signature **"Make This Query 10x Better" Lab**, non-sargable query refactoring, and cost-based execution plans.
14. **Level 13 — Database Security & SQL Injection**: Interactive **Security Sandbox** attacking an unescaped login with `' OR '1'='1` and defending via Parameterized Queries.
15. **Level 14 — Database Programming**: Connecting databases with Java (JDBC), Python (psycopg2/sqlite3), and Node.js (pg/mysql).
16. **Level 15 — Databases Across The Industry**: Relational, Document, Key-Value, Wide-Column, Graph, and Serverless Cloud databases.
17. **Level 16 — Database Comparison Engine**: Dedicated head-to-head architectural showdown matrix across MySQL, PostgreSQL, Oracle, SQL Server, MongoDB, Redis, Cassandra, Neo4j, and SQLite.
18. **Level 17 — Database in Real Industry**: Production schemas and trade-offs across 8 sectors: Banking, E-Commerce, Healthcare, Education, Aviation, Telecom, Social Media, and Logistics.
19. **Level 18 — Database Evolution**: Interactive visual timeline from 1960s flat files to 2026 AI vector and serverless engines.
20. **Level 19 — Database Architecture & Distributed Systems**: Master-Replica replication, consistent hash sharding, and the CAP Theorem.
21. **Level 20 — NoSQL Deep Dive**: Solving the identical e-commerce problem across MongoDB, Redis, Neo4j, and Cassandra.
22. **Level 21 — Database Engineering**: WAL archiving, Point-In-Time Recovery (PITR), schema migration pipelines, and zero-downtime deployments.
23. **Level 22 — 10 Major Real Projects**: Complete production database blueprints with schemas and queries:
    - 1. Student Management System
    - 2. Library Management System
    - 3. Hospital Management System
    - 4. Banking & Financial Ledger
    - 5. E-Commerce Database System
    - 6. Food Delivery Platform (Swiggy/Zomato style)
    - 7. Employee Payroll System
    - 8. College ERP Database
    - 9. Hotel Booking Database
    - 10. Enterprise Multi-Tenant Architecture Project
24. **Level 23 — Placement Preparation Engine**: 100+ SQL Coding Challenges categorized by difficulty (Basic, Intermediate, Advanced, Expert) + Top 50 FAQs.
25. **Level 24 — AI-Style Interview Simulator**: 7 simulated rounds covering fundamentals, SQL, query solving, database design, performance, scaling, and disaster recovery.
26. **Level 25 — DBMS Placement Readiness Index**: 8-dimension readiness index benchmark, personalized Learning Intelligence Report, and verifiable certification.

## 🛠️ Integrated Technologies & Features
- **Browser-Based In-Memory SQL Engine**: 100% offline relational query execution engine supporting DDL, DML, DQL, Joins, Aggregates, Transactions, and `EXPLAIN` query plans without external server calls.
- **Progressive Web App (PWA)**: Standard `manifest.webmanifest` and Service Worker (`sw.js`) enabling installability on Desktop and Mobile, functional completely offline.
- **Kapil's DBMS Mentor**: Integrated AI mentor explaining WHY, WHAT, HOW, WHERE USED, COMMON MISTAKES, and INTERVIEW QUESTIONS for any topic or query.
- **Verifiable Certification & Public Verification Portal**: Milestone certificates and final *Industry Readiness Certificate* equipped with unique IDs (`SY-DBMS-2026-XXXXXX`) and dynamic QR code verification.
- **Admin Dashboard**: Tracking cohort progression, most difficult lessons, most failed SQL challenges, and content intelligence alerts.
